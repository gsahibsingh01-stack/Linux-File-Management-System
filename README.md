# Linux File Management System

## Project Description

The Linux File Management System is a beginner-level BCA mini project developed using Linux commands and Bash Shell Scripting.

It provides a menu-driven interface to perform basic file and directory operations in a Linux environment.

## Objectives

- Learn basic Linux commands.
- Manage files and directories.
- Understand Bash Shell Scripting.
- Perform file operations through a menu-driven interface.

## Features

- Create files
- Create directories
- List files and directories
- Copy files
- Move files
- Rename files
- Delete files
- View file contents
- Search files

## Technologies Used

- Linux Operating System
- Bash Shell Scripting
- Linux Terminal

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Give execute permission to the script.
4. Run the application.

```bash
git clone https://github.com/YOUR-USERNAME/Linux-File-Management-System.git

cd Linux-File-Management-System

chmod +x file_manager.sh

./file_manager.sh
```
